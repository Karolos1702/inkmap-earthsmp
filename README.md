# InkMap EarthSMP — wydania / releases

**PL:** To repozytorium służy wyłącznie do dystrybucji aktualizacji aplikacji **InkMap EarthSMP** (mapa na żywo serwera InkMC.pl EarthSMP). Nie zawiera kodu źródłowego, tylko pliki instalacyjne w zakładce [Releases](../../releases).

- **Instalator** (`…-setup.exe`) – zalecany: aplikacja sama pobiera i instaluje nowe wersje.
- **Wersja przenośna** (`…-portable.exe`) – bez instalacji; o nowej wersji dostaniesz powiadomienie, ale plik trzeba pobrać ręcznie.

**EN:** This repository only distributes updates for the **InkMap EarthSMP** desktop app (a live map for the InkMC.pl EarthSMP server). It contains no source code, just the installers under [Releases](../../releases). The installed version updates itself automatically.
